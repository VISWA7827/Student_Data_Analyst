# 📊 Student Performance Data Analysis (Classes 6–10)

## 📌 About the Project

This project analyzes student academic performance from Classes 6 to 10 using Python, Pandas, and Excel. It focuses on data cleaning, handling missing values, calculating marks, and analyzing student performance across six subjects.

## 🎯 Project Objectives

- Analyze student marks from Classes 6 to 10.
- Identify and handle missing values.
- Calculate total marks and average marks.
- Find the highest and lowest marks in each subject.
- Compare class-wise student performance.
- Analyze student results and attendance.
- Generate useful insights from student data.

## ⚙️ Installation

Make sure Python is installed on your computer.

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries.
4. Ensure the Excel file is inside the `data` folder.
5. Run the Python script:

```bash
python student_analysis.py
```

## 📈 Pandas Concepts Practiced

- Reading Excel files using `read_excel()`
- Inspecting data using `head()`, `info()`, and `describe()`
- Detecting missing values using `isnull()`
- Handling missing values using `fillna()` and `dropna()`
- Grouping data using `groupby()`
- Sorting records using `sort_values()`
- Filtering rows and selecting columns
- Calculating minimum, maximum, and average marks
- Counting categories using `value_counts()`
- Exporting results to Excel
